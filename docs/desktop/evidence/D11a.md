# D11a 调度冻结快照、恢复与通知修复

日期：2026-09-18。状态：done。

## 实现

- `DesktopJobService.create_snapshot` 可按工作空间加载精确 `rule_version_id`；调度执行同时传冻结的筛选、简历和评分版本，规则缺失或越工作空间时失败，不回落默认权重。
- `running` 使用 15 分钟运行租约。过期运行在下次轮询时原子标记 failed、记录断电/异常退出原因并产生一次可操作通知；任务后续计划继续执行。
- SQLite 的唯一计划槽继续负责跨调度器去重；Electron 新增轮询互斥，避免同一后台来源视图被两个并发轮询覆盖。
- Electron 先预览到期任务，为每个任务使用相同后台来源动作桥收集页面，再执行 Python 调度；浏览器来源不再绕回旧 CDP 或永久失败壳。
- 只有系统通知实际触发 `show` 事件后才确认送达；不支持或失败时保留未送达记录供后续重试。完全退出仍停止轮询并终止 Python 子进程。
