# D10a 研究证据正文核验与模型事实边界

日期：2026-09-18。状态：done。

## 实现与结论

- 搜索 RSS 只作为候选发现。系统随后读取同一受支持站点的 HTTPS 原始页面，限制响应类型/大小，拒绝越域跳转；正文不足或未出现目标公司时只记录来源状态 `search_summary_only`，不写入已核验证据。
- 入库的 `independently_retrieved` 现在只对应 `original_body_verified`：正文已读取且公司名称匹配。团队未在正文出现时降为公司级材料；发布日期只取原页元数据，缺失时明确“不可核验”。
- 模型载荷仅含最多 12,000 字的脱敏简历事实与 JD，不再发送口碑正文或用户摘录。模型生成内容统一标记“建议（需用户核实）”，不作为简历事实或公司评价。

## 最小验证

- `uv run pytest -q tests/desktop_api/test_research.py tests/models/test_gateway.py tests/security/test_analysis_copy.py`：17 passed。
- 样例覆盖同站正文、越域跳转、公司不匹配、团队未知、原页日期缺失、搜索摘要不得入库，以及模型载荷不含评价材料。
- 受影响 Python `ruff check` 与 `ruff format --check` 通过。

## 限制

动态渲染或要求登录的评价原页可能无法直接读取；此时只报告 `search_summary_only` 或受限，不生成口碑结论。没有再次联网抓取社区正文。
