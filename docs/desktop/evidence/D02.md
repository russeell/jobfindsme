# D02 桌面端与本地服务底座

日期：2026-09-18。结论：通过。

## 实现

- Electron 主进程分配回环端口和 256-bit 启动令牌，启动 FastAPI 子进程；窗口或信号退出时先 SIGTERM，超时才 SIGKILL。
- API 只允许 `127.0.0.1/::1/localhost`，所有当前路由需 Bearer 令牌。`/v1/bootstrap` 从现有 `jobfindsmecore` 读取真实工作空间，不使用示例岗位。
- renderer 启用 sandbox/context isolation，关闭 Node integration 与任意窗口/导航；preload 仅暴露 `getBootstrap()`。
- React/TypeScript 界面沿用灰白、左导航与列表/右侧工作区。未接通的检索、登录、投递及后续页面均明确禁用。

## 验证

- `uv run pytest tests/desktop_api/test_app.py -q`：3 passed；覆盖无/错令牌 401、真实核心启动数据、来源门禁和 API 子进程启停。有一条上游 anyio 弃用警告。
- `ruff check` + `ruff format --check` 针对 desktop_api 与测试：通过。
- `npm run build`：TypeScript 两个配置的类型检查、Vite 生产构建和 Electron 主进程编译通过。
- `npm test`：1 passed，检查来源能力契约的禁用/匿名边界。
- 桌面冒烟：`npm start`。Electron 窗口实际显示“本地服务已连接”、0 个真实工作空间、猎聘可尝试及三来源已禁用；灰白双栏和右侧来源面板可见。退出后 Electron 窗口消失。

## 限制

当前只是阶段 A 底座。未接入岗位检索、简历、平台 WebContentsView 或投递操作；这些控件保持禁用，不代表已完成后续任务。
