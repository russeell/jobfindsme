# D50 验收记录（2026-09-24）

## 结果

- 简历页只保留上传、事实核对、确认和清除。旧求职偏好表及接口留作历史兼容，找工作页不再读取或自动套用旧偏好。城市、薪资和来源继续在找工作页设置。
- 已确认简历可在关键词为空时生成最多 4 个经过隐私字段过滤的检索词；返回结果显示实际使用词。无简历或待确认草稿时需手动输入关键词；清除当前简历后旧事实不参与新检索。手动关键词优先。部分来源失败保留成功来源的结果。
- “口碑调查”改为“岗位研究”。公司研究按经营、上市、正面反馈、负面反馈、工作强度、日常福利查询；岗位研究按内容和发展查询。官方披露与个人陈述分别标注，原页核验、日期、来源范围和冲突提示保留。发展分析需要 JD 技能与已核验经营证据；缺失时保持未知。旧报告仍可重新打开。
- 研究查询使用有界 Bing RSS 和原页核验：总预算 45 秒、单次请求最多 4 秒；无付费模型调用。公告 PDF 暂不解析正文，因此某些上市信息可能显示未知。
