# D08 模型连接与统一调用

日期：2026-09-18。状态：done（真实连接保持未验证）。

## 实现

- `ModelGateway` 提供 `generate_structured / stream / cancel / usage` 统一契约，分别映射 OpenAI 兼容、Anthropic 原生和 Gemini 原生请求/响应及 token 用量。
- 非秘密配置保存到 `model_connections`；新建或修改后状态为 `unverified`。连接测试只在用户显式点击时使用最小请求，有 15 秒后端超时与 18 秒桌面调用上限，可取消并记录 `cancelled`。
- API Key 不进入 SQLite、响应、前端持久化或错误日志；Electron `safeStorage` 加密后写入权限 `0600` 的独立文件，仅测试时在主进程取出并短暂传给回环 API。系统安全存储不可用时拒绝保存 Key。
- HTTP 错误不保存服务端响应正文，避免恶意端点回显密钥后进入状态/日志。非本地自定义端点强制 HTTPS。

## 验证

- 三类协议分别用注入的脱网 transport 样例验证 URL、请求体、响应取值和用量映射；预取消请求不进入 transport。
- API 样例验证配置不包含 Key、新连接未验证和取消状态。
- `npm --prefix apps/desktop run build` 及 `npm --prefix apps/desktop test`：审查修复后通过，Node 8 passed。Electron 实际启动显示系统安全存储可用。
- 未读取任何其他应用密钥，未发起付费或真实模型请求；因此所有新连接在用户自行配置并显式测试前保持未验证。
- 独立审查的取消/超时竞态、密钥配对和 Gemini URL 暴露发现已修复，详见 `D03-D08-review-resolution.md`。

唯一对照为 desktop-v3 的模型设置页：保留最大 760px 设置宽度、服务商/协议双列、端点/模型/Key 整行及灰白面板。必要扩展是在同一设置区下方显示真实连接状态、取消、超时、用量和密钥是否安全保存。
