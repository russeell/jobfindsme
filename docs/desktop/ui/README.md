# UI 实现基线

`jobfindsme-desktop.html` 为用户已查看的第三版可交互原型，原样归档。
它是唯一视觉基线（`desktop-v3`）；原件同步来源为 `/Users/russeell/.codex/visualizations/2026/09/18/01a0b37c-a94a-76a0-a521-5fdfc6f3977c/jobfindsme-desktop.html`。不使用绿色 `jobfindsme-ui.html` 或早期 `neutral-v2` 作为实现依据。
保持灰白配色、左侧导航、岗位列表与右侧详情/研究/浏览器切换；窄屏切换列表/详情，不把详情接到全部岗位之后。
生产页必须在该版导航分组、页面布局、留白、卡片和右侧工作区结构上接通真实功能，不得只保留灰白配色而重做另一套布局。

原型之后确认的需求，必须以新方案为准补齐：

- “加载更多”改为默认 20 条的真正分页，绑定稳定结果快照。
- 简历编辑增加自由 Prompt、多轮修改、逐段差异采纳和模板导出。
- BOSS、智联、前程无忧未登录禁止检索；猎聘允许匿名尝试。
- 存在已确认简历时，检索词和排序必须使用该版本。
- 模拟登录、解析、投递、调度与模型配置逐步接入真实用例；虚构数据不得混入生产。

此文件仅作参考，不直接作为生产 UI 架构；后续按任务迁移为可维护组件。

## 配色实现约束（2026-09-19）

桌面产品保持清爽灰白：工作区白色，侧栏浅灰，主操作深灰。`apps/desktop/renderer/src/theme.css` 最后加载，负责统一表面与原生控件主题；新增组件复用其变量，不引入大面积蓝灰或彩色提示背景。状态通过文字及少量语义色区分。
