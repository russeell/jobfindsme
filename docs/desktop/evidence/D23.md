# D23 前台浏览与后台来源权限分离

2026-09-19。用户明确授权前台普通HTTP/HTTPS尽量按Chromium浏览，不再按登记来源拦截；不是取消后台采集门禁。随最终UI9交付。

- 前台任意正常HTTP/HTTPS地址、跨域导航/重定向、新标签允许；登记入口固定分区，弹出标签继承打开者分区，未知入口通用persist分区。原页动作也可打开未登记来源。
- 后台列表/详情/岗位解析仍有各自白名单及能力/登录检查，执行脚本前核对最终URL；前台能浏览不代表可自动检索。
- 保留Node关闭、contextIsolation/sandbox/webSecurity与证书验证。网页无preload/应用IPC；特殊协议和本地/内部地址拦截，不导出Cookie。权限需明确选择，下载保存对话框，不自动唤起外部应用。
- 用户截图问题在真实阿里官网复核：点击实际存在的第二个“进入招聘官网”，新标签成功打开 `https://talent.taotian.com/`（此前未登记域），同一个Electron session，正文可读，无阻止提示。另从阿里上下文打开Apple招聘，重定向到 `https://www.apple.com/careers/cn/`；普通 `http://example.com/` 使用web分区且可返回原标签。没有登录、真实申请或读取Cookie。
- 原生view在城市筛选浮层出现时getVisible=false，Escape后恢复true。remote `typeof require` 与 `typeof window.jobfindsme` 均undefined；实际preferences隔离项正确。javascript地址没有增加标签。
- 策略/标签定向测试与D24一起22通过，包括前台通用URL、后台仍拒绝其他来源、异常协议/回环形式、跨站继承分区、标签资源上限。
