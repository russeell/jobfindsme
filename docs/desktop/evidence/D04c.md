# D04c 内嵌会话来源动作桥与分页适配

日期：2026-09-18。状态：done（无需账号的实现验收）；D01/D04 真实登录终验保持 blocked/pending。

## 实现

- BOSS、智联、前程无忧由各自后台 `WebContentsView` 执行固定动作：构造白名单 HTTPS 搜索 URL、读取有限列表字段、最多三条详情正文和分页状态。后台视图与前台视图分离、复用同一持久分区，不打断用户浏览。
- renderer 只能从主窗口 preload 发起搜索；主进程核对 `event.sender`。动作脚本由代码固定，未提供任意 URL/脚本接口；结果再次检查来源主机、字段类型和长度。远程页无 preload、Node、Cookie 导出或公共 CDP。
- 登录页或验证码/风控标记立即停止；后端把 session 标为 expired/blocked、list 标为 blocked 并禁用，不尝试绕过。
- 猎聘 JSON 连接器现传真实 `currentPage` 并返回继续游标，不再永久停在首页。
- 11 家官网中只有腾讯公开招聘 JSON 接口实现为适配器；其余 10 家仍为 disabled/unverified 目录，不把招聘首页当可用列表。

## 单次公开来源实测

- 只读请求腾讯官方公开接口 `careers.tencent.com/tencentcareer/api/post/Query`，关键词 Python、第一页 2 条：HTTP JSON `Code=200`、`Count=343`，返回岗位 ID、公司、地点、职责、更新时间和详情 URL。未登录、未读取 Cookie、未投递。
- Agent Reach 的 Exa 搜索先用于定位接口资料；受 sandbox 网络限制后按授权重试一次。腾讯官方接口随后用单次 `curl` 直接验证。其他公司没有逐站试探或绕过封锁。
