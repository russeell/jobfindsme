# D48：界面修复与定时检索停用

2026-09-24。本轮只使用离线合成数据和独立预览用户目录；没有读取或覆盖用户简历、登录会话和正在运行的旧实例。

## 结果

- 岗位来源：检查全部来源改为页首轻量操作，仅在执行时显示有界进度和取消；逐卡显示本次结果，诊断与长说明折叠。单源与总预算、风控和登录门禁未改。
- 匹配规则：提示词和保存为主，模板、名称、评分及历史折叠；本地评分不会使用自由提示词的说明直接可见。历史规则支持删除，当前或被搜索、旧计划引用的版本受保护；跨工作区不允许删除。
- 简历：事实类型中文化，当前页及发现页去掉无意义版本号，空基本信息块不展示；编辑过程保留空格、换行和空白行，保存与重新打开保持一致。旧版移除有行内确认和错误反馈，当前及被引用版本受保护。
- 口碑：历史报告的名称、日期、状态和移除操作分开；报告标题、时间、主题与证据层级调整；提供独立的“选择调查主题”返回入口，无证据时沿用明确的未知说明。
- 用户明确要求彻底停用定时检索：移除桌面入口和启动轮询；API 拒绝新建/恢复计划，待执行列表为空，运行接口不执行也不补跑。原有计划、运行记录与引用快照在本机保留，手动检索不受影响。CLI 没有单独的计划执行入口；内部 LocalScheduler 类保留供历史格式兼容，但产品桌面/API 不再调用其执行路径。旧版实例若继续运行，其旧代码仍可能调度；需退出旧版并使用本包才应用停用逻辑。

## 验证

- `.venv/bin/python -m pytest tests/desktop_api/test_matching_prompts.py tests/resume_editor/test_service.py tests/desktop_api/test_scheduler.py tests/desktop_api/test_app.py -k 'not process_starts_and_stops_cleanly' -q`：22 通过，1 项因沙箱禁止绑定回环端口未运行。覆盖旧计划重启不补跑、新建/恢复被拒、手动匹配、历史删除与简历空格换行。
- `npm --prefix apps/desktop run typecheck`：通过；`npm --prefix apps/desktop test`：76/77 通过，唯一失败是沙箱禁止 `127.0.0.1` 监听（`listen EPERM`），不是断言失败。
- Python runtime 重新冻结、macOS 普通包与独立 QA 包打包，`audit:mac:dir` 通过。普通包 `/private/tmp/JobFindsMe-D48-UIFix.app` 未启动。
- 独立 QA 原生界面（默认约 1160px、窄窗约 820px）用合成简历保存含前后空格和空白行的项目，离开页面再进入后文本仍完整；合成旧版本可移除。离线合成报告验证历史布局、报告层级、窄窗及返回主题，不发起线上调查。
