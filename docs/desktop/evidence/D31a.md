## 实现

- 复用 Electron `persist:jobfindsme-source-boss`；前台登录、后台列表和独立详情视图使用同一平台分区。搜索引擎的通用网页会话不自动搬运到 BOSS；UI 明确从岗位来源打开。未读取/导出 cookies，未复制真实 profile，也未建立外部 Chrome/CDP 链路。
- 只在当前可见 BOSS 标签本地读取已加载 DOM（2.5秒间隔），不发登录探测网络请求。消息/简历导航、登录表单、岗位卡片或明确空态共同判断。验证码优先暂停；历史登录失效后不能凭未刷新的旧页面重新启用，须观察登录表单转换或新导航。风险暂停须用户在原页处理后明确恢复。
- `/web/geek/jobs` 使用 query 与城市代码。11个城市代码沿用本项目旧连接器映射；未知城市明确不执行。当前多城市选择仅检索首个城市，UI及来源覆盖明确提示未覆盖其他城市；不冒称跨城市全量检索。
- 手动、定时与所选详情共享串行队列；相同在途检索合并，列表缓存2分钟，详情缓存30分钟。来源动作默认至少间隔2.5秒；契约/网络失败退避30秒并有界增长至5分钟。验证码/登录失效立即停源。
- 每次最多3批、100个去重岗位、至多60秒（UI通常15秒）；滚动累积卡片，支持虚拟列表替换；明确到底、连续两批无增长、时间/数量预算或取消分别报告。继续下一批必须用户点击，游标绑定当前查询和列表上下文，10分钟失效。快照分页与平台滚动批次分开命名。
- 先列表、后最多2个关键词相关候选的完整 JD；时间不足时保留列表，也可显式读取所选岗位。独立详情视图不破坏列表滚动。描述只来自目标岗位详情节点；展开状态、缺失正文不冒称完整。保存规范岗位 URL 与实际读取时间，保留纯文本段落和 C++ 等符号。私用字体薪资保持未知。
- 取消及风险中断保留已读岗位。后端先保存本次部分结果再撤销来源能力，避免旧逻辑先禁用门禁导致结果全丢。进度、已读标题预览、停止、部分覆盖和下一批入口可见。
