## 实现

- 增加 PyInstaller arm64 单文件运行时规格，显式收集包元数据、迁移和资源；固定 asyncio/h11，产品运行不依赖源码目录或 `uv`。
- Electron 生产模式从 `Contents/Resources/python/jobfindsme-api` 启动；开发模式仍使用项目虚拟环境。macOS 本地目录包脚本只复制 renderer、Electron main/preload 和 Python 运行时。
