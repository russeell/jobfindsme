# D27 浏览器新标签：网址与搜索统一入口

2026-09-19，隔离包 `D27-20260919-ui11`。

- 控件改为“搜索关键词或输入网址”，按钮“打开”；Bing 默认，百度/Bing 选择保存在本地并跨进程恢复。
- 只选网站：打开其首页（四个招聘平台不再从新标签入口跳登录页）。
- 输入 HTTP/HTTPS 或常见无协议域名：打开输入网址，优先于网站选择；摘要明确“将打开输入网址”，按目标来源选会话，不借用下拉中不同网站的身份。
- 只输入关键词：所选引擎全网搜索。网站加关键词：`site:已登记域名 关键词`，明确显示站点限定搜索；不调用后台岗位检索或自动填站内搜索表单。
- 提供“清除网站，恢复全网搜索”；空态禁用，危险/畸形 scheme 和本地网址禁用。一次提交仅打开/复用一个目标。
