# D16 四维匹配规则

2026-09-19；当前未提交工作树。

- 新规则仅技能35、项目经历30、学历15、工作经验20；前后端校验非负整数且合计100。本机保存新权重，后续检索和新任务使用新版本。
- `desktop_rules.py` 从已确认简历的skills/projects/experience/education映射证据；技能对应JD技能；项目要求行动/贡献描述后才计算覆盖，裸关键词不得分；学历最低要求对比已取得学历，在读不当已取得；工作年限用明确陈述或不重叠工作日期区间，排除实习，不用年龄或毕业年份推算。未知计0并单列证据不足，不假装满足。
- 历史兼容采用保留读取：旧四项键仍按旧算法计算，旧规则ID/weights JSON/历史scores不修改；新四项键生成不同immutable规则ID，历史及旧定时任务保持原快照。无需破坏性数据库迁移。
- 审核了模型链路：桌面排序未调用模型；模型只用于研究/简历文本，没有可由模型覆写的匹配分数字段。预览/搜索分数统一来自同一确定性evaluate函数，不从模型自由文本取分。
- 规则页滑杆+数值、合计校验、默认恢复；可预览发现页当前岗位或本地已有岗位，调用鉴权API重新计算，不覆盖历史。发现详情显示对应历史/新版评分明细。
- 定向测试：新增四维/未知/纯关键词/工作区间去重/学历不足/年限部分达成/旧新规则快照/API鉴权6通过；原快照及调度8通过；API9项通过，需回环端口的进程测试单独提权后通过。类型构建和相关ruff通过。
- 原生UI：无岗位明确空态；35改40使总和105，保存禁用；恢复默认可保存，刷新保留。已有腾讯岗位结合隔离测试简历预览11.67分，技能11.67/35，项目0/30，学历年限明确未知。修复长岗位标题select导致横向溢出，截图 `D16/rules.png`。
- 定向测试简历为隔离数据，预览不是用户真实匹配建议。仍为启发式证据对应；不宣称学历或工作经历已外部核验。
