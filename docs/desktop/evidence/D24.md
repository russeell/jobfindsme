# D24 紧凑工具栏与真实页面适应宽度

2026-09-19，`D24-20260919-ui9`，最终包 `/private/tmp/JobFindsMe-D24-UI9.app`。

## 根因与修复

工具栏原本标题、缩放、URL三行且min-height=82，留下明显空白；改为标签行下单行导航/地址省略/缩放/放大/关闭，错误单独按需展开，原生bounds随实际高度更新。测试工具栏高41.75px，原生view从y96开始，没有盖住按钮。

旧适应公式依赖当前zoom，无法把120%回到正常上限；腾讯页面还隐藏根部overflow，document.scrollWidth=viewport并不代表内部内容未被裁切。首次改为100%基准但只看document宽度仍不够，原生截图发现申请控件仍被裁切，因此补测可见元素的实际布局边界，最多3轮只缩小校正。所有测量是读取DOM；没有隐藏客服或改网页样式。

每次适应以100%为基准，最高100%，最低30%；等待主框架加载稳定，导航/测量失败明确报错并恢复原zoom；同标签适应中重复操作去重。手动放大仍到200%，恢复100%保留；各标签zoom独立。超宽页面到下限会提示横向查看。

## 真实验证

已实际打开腾讯既有验收URL `https://careers.tencent.com/jobdesc.html?postId=2034114862627581952`，页面标题“轻量云OpenClaw AI Agent 高级工程师”。未登录或点击申请。

- 从120%、100%、60%各自连续适应3次，649px原生面板均稳定63%。CSS视口1006，申请控件右缘986.36，真实按钮与正文右侧完整可见。
- 放大主区后1175px面板适应100%；返回分栏649px重新适应63%；860×720窄窗面板663px适应64%。
- 另开标签手动110%后切回，原标签值不串；恢复100%实际webContents factor=1。
- 22项浏览器/策略测试通过，TypeScript/构建与目录包audit通过。旧仅根scrollWidth检查不足，已用真实申请控件右边界和原生截图替代，修复后重验通过。
