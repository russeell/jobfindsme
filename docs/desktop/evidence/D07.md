## 实现

- 结构化编辑以当前 `resume_version` 为乐观锁基础，保存生成新版本；陈旧基础版本返回冲突，不覆盖并发修改。
- 回退会复制目标内容并创建新的当前版本，保留完整父版本链，不把历史行直接改回当前。
- `classic` 与 `compact` 两款单栏模板共用同一结构内容；桌面页沿用 `desktop-v3` 的导航、灰白卡片、留白及右侧工作区，增加模板预览、版本历史和导出入口。
- PDF 使用内嵌 CJK 字体分页输出，DOCX 使用中文字体映射，MD 使用 UTF-8；导出文件权限为 `0600`。旧 DOC 与扫描 PDF OCR 继续明确显示为缺失能力及替代路径。
