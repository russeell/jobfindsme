# D03 简历导入、核对、版本与隐私

日期：2026-09-18。状态：done。

## 实现

- 复用现有 `ResumeTextExtractor` 的 PDF/DOCX/MD/TXT 限额提取和确定性事实解析；桌面端只通过原生文件选择器传入选定路径，preload 不暴露任意路径读取。
- 导入后保持 draft，显示可编辑的候选事实；`search_profile_state=pending_confirmation` 和阻塞原因作为后续 D04 的强制门禁契约，不静默降级为无简历。
- 确认与新 `resume_versions` 当前版本在同一 SQLite 事务内写入；新版本保留父版本、来源文档 ID 和结构化事实，不把原文全量复制到版本表。
- 分析副本按用户选择过滤姓名、电话、邮箱、地址和身份证，仅临时生成，不改写原件或当前版本。
- 能力状态明确显示：旧 DOC 尚未支持，需转 DOCX；扫描 PDF OCR 尚不可用，解析错误不伪装成成功。
