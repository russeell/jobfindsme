# D54 研究工作区与无链接公司提问

2026-09-24，分支 `codex/desktop-refactor`。用户明确要求窗口不要固定为 1:1；原生窗口仍可自由调整。

## 实现

- 报告和底部输入共用工作区宽度，正文只有一个滚动容器。顶部操作收敛为返回、历史和「更多」，上下文过长时省略显示；输入默认两行，随文本增高后内部滚动，主题芯片与发送同排，状态放在输入框外。
- 不贴岗位链接时，可直接询问明确公司的问题。岗位话题需要明确岗位名；对象不明时保留问题并要求补充。使用原有有界公开来源检索与原页核验；无岗位请求不造假岗位或 JD，也不生成简历改写。
- `0035_company_research.sql` 允许研究报告的 `job_id` 为空，并保留真实岗位外键、旧报告、证据及更正。公司研究按公司连续编号，历史中与岗位报告区分并可重开。研究失败或取消保留已显示的报告。

## 限制

本轮未使用真实招聘账号，也未发起线上研究或付费模型调用。真实公开来源可获得的具体证据仍取决于平台可访问性。D01 的 BOSS、智联、前程无忧真实登录及来源验收继续阻塞；Chrome 的智联登录页不能替代应用独立会话的登录验收。
