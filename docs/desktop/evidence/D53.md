# D53 岗位研究响应式布局与统一输入（2026-09-24）

## 实现

- 窗口保持自由宽高，不锁定 1:1。研究页按工作区高度分为顶部操作栏、独立可滚动且可键盘聚焦的报告正文、底部输入区。历史报告、返回研究首页、返回找工作、岗位原页均在顶部工作区栏，正文无重复按钮。短窗缩小输入高度，长问题在文本域内滚动，主题与提交始终可见。
- 岗位链接和自然语言问题合用一个输入框。输入中的单个 HTTPS 链接先按现有来源白名单校验并读取候选岗位，确认后保留提问文字；当前已有岗位时，无链接问题可直接继续研究。模糊链接、多个链接和不支持来源直接提示；读取失败、取消或研究失败不替换当前报告。读取状态与错误显示在底部输入区。
- 设置位于侧栏底部，移除工作空间状态注释和常驻调试页脚。版本信息放入设置的「关于」。工作空间隔离和本地服务状态逻辑未改。
