# D22 版本化提示词与有界模型重排

2026-09-19，最终 UI9。实际付费模型未调用；协议返回由本机模拟服务生成，并明确标记“合成协议验收”，不能当作真实模型质量评估。

## 实现

- 通用、校招/实习、社招模板及可编辑提示词。保存生成不可变规则版本并启用；可载入历史草稿后另存，旧维度只读。四项权重收进高级设置。
- 本地规则立即给结果；显式保存模型模式后，对前1–20个候选进行一次模型请求（60秒，输出最多8000 tokens），仅在候选池内排序，其余顺序保留。原始快照不修改，模型结果另存派生快照。显示正在检查、覆盖数量、取消、失败保留本地结果。
- 模型配置及提示词随规则冻结，新建任务使用当前版本，旧任务仍用原版本。主进程取安全存储密钥，不写规则或renderer；调度部分失败保留本地结果并显示/通知原因。
- 分析副本排除基本信息、过滤常见身份字段；简历分析最多8000字，每岗JD最多2400字。试算先预览实际发送载荷。JD为不可信资料，结构化分数、候选集合及双向逐字引用都校验；未知允许null分，不能凭空补证据。无法从格式校验保证模型判断质量，引用可由用户核对。
- 没有已确认简历时显示“尚未评分”，试算阻断，不展示假0分；本地模式明确自由提示词不参与评分。
