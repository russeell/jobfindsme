# D09 验收证据

日期：2026-09-18。结论：完成；未调用真实或付费模型。

## 实现

- Prompt 会话绑定工作区、当前简历版本和已验证模型连接；每轮支持自由指令、用户确认的项目事实及可选 JD。JD 在模型指令中明确按不可信参考文本处理，不扫描代码仓库。
- 仅用户点击“生成修改建议”时，Electron 才从系统安全存储读取与连接配对的 Key 并经受限回环 API 调用；未验证连接、无 Key 或无用户操作均不发送。请求复用既有取消令牌与本地 transport 关闭机制，并保留“请求已到服务商仍可能产生用量”的限制。
- 脱敏覆盖整个发送载荷，包括自由 Prompt、结构化简历、补充事实、可选 JD、证据表与历史补丁；默认过滤全部身份类型。开启任意过滤时额外省略基本信息段；用户取消全部选项才表示明确保留。模型回传中的可识别身份字段也会再次过滤并阻止直接采纳。
- 模型只返回结构化段落补丁；`before` 必须精确匹配基础版本，证据 ID 必须存在。新增数字、成果词或无依据技术/专有名词会标记“待补充”并禁止采纳。
- 支持多轮补丁、逐段采纳/拒绝/撤销。同一段仅保留一个已采纳候选；保存会再次检查基础版本并另存新版本，原版本和原文件不自动覆盖。

## 限制

- 未使用用户模型配置或 Key，真实服务商生成保持未验证；测试模型输出仅通过注入 transport 进入测试进程，不会进入生产数据。
- 取消能停止本地等待/读取，不能撤回已抵达服务商的请求，也不能保证免计费。
- 自动事实检查是保守边界，不能替代用户对语义真实性的最终判断；因此任何模型结果仍只作为候选补丁，且保存前必须明确逐段采纳。
