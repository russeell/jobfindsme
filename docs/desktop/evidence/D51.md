# D51 对话式岗位研究验收（2026-09-24）

## 实现

- 研究对象来自找工作或已看过的岗位；没有对象时可粘贴并确认岗位原页。公司情况和岗位情况作为输入框内可多选主题，默认都选中，问题可留空。
- 自由问题与岗位、公司一起进入有界公开网页查询。问题本身作为单独的优先查询角度，报告明确列出本次问题对应的原页与时间、主体范围；没有直接可核对材料时说明无法回答。全程不自动选择模型或付费连接。
- 报告页可返回研究首页，右上角历史报告可重开版本、查看其他岗位或移除记录；返回和更新保留旧版。失败报告留在历史，当前阅读版不被替换。
- 不付费的研究同样有服务端取消令牌：取消后在下一次网络请求前停下；正在进行的单次请求最多 4 秒。取消前的报告不被覆盖。研究总预算 45 秒。
- 已看过仍承载阅读、收藏和投递状态，取消收藏不移除研究报告。来源原页按需在原生右侧面板打开，报告与原页为并列布局。
