# D44 全部来源有界检查

日期：2026-09-23；交付版本：`D45-20260923-ui33`。

- “检查全部来源”将 4 个招聘平台、16 个公司官网依次送入同一队列。符合门禁的来源实际读取一个岗位列表页，每源最多 8 秒、整队列最多 45 秒；不抓取 JD 或网站续页。逐源结果分别标明本次探测、最近缓存、历史登录/风控状态、未轮到、失败或取消，并显示能力分项及验证时间。来源勾选与已保存任务快照不受影响。
- BOSS、智联和前程无忧在应用独立会话未确认登录时跳过；遇风控、冷却时不重试。取消或超时保留已完成结果，尚未访问的来源标为未检查。公开来源使用现有适配器与服务端前置检查；强制刷新列表缓存，以免把旧记录当本次成功。预览包额外限制只做 1 次真实探测，普通交付包按 45 秒总预算运行。
- 受控队列测试覆盖 20 来源入队、登录/缓存/风控门禁、取消、单源超时、总预算和预览探测上限，6/6 通过。Python 公开来源刷新接口 16 项测试通过；桌面 Node 全量 77/77、TypeScript、ruff 与打包审计通过。
- 原生隔离 QA33 包在默认宽度与 854px 窄窗完成验收。点击后 20/20 均有结果：猎聘本次读取到列表并通过，智联等 3 个平台标为应用内登录未确认，其余 16 个公司官网标为预算未轮到；猎聘 JD 为“部分可用”、网站续页“待验证”，没有扩大宣称。该包只对猎聘做了 1 次在线探测，未做 20 来源实时扫站。
- 用户提供的智联官方登录 URL 与应用入口一致。Chrome 登录态不会同步到应用独立会话；本次没有登录智联，也没有核验其登录后的列表、JD 或网站续页。
