# D04a 隔离来源浏览器与能力状态底座验收证据

日期：2026-09-18。结论：离线可验收底座完成；真实平台登录与兼容性仍属于 D01/D04。

## 实现

- Electron 主进程新增右侧 `WebContentsView` 来源浏览器。BOSS、猎聘、智联、前程无忧分别使用 `persist:jobfindsme-source-<id>` 持久分区；每个平台分别创建前台人工浏览视图和未挂载的后台检索视图，两者复用该平台 session，后台导航不会打断用户当前页面。
- 远程视图未配置 preload，`nodeIntegration=false`、`contextIsolation=true`、`sandbox=true`、`webSecurity=true`；只允许 HTTPS 平台域名，拒绝新窗口和越界导航。没有 Cookie 导出接口，也不使用公共 CDP 端口。
- 新迁移保存 `session / list / detail / fields / pagination` 五类状态、最近验证时间、启用状态和限制说明。三项登录来源默认 unverified/disabled；猎聘沿用 D01 的 2026-09-18 匿名列表实测，仅 list 标 verified、fields 标 partial，完整 JD 与分页仍 unverified。
- 来源页沿用 `desktop-v3` 左导航、灰白留白卡片与右侧工作区。11 家官网与四平台分别展示能力，不把登录成功或主页可打开等同于检索可用。

## 验证

- `npm run typecheck`：双 TypeScript 配置通过。
- `npm test`：`11 passed`，其中覆盖四个独立持久分区、HTTPS/域名白名单和视图边界约束。
- `npm run build`：生产 renderer 与 Electron main/preload 构建通过。
- Python 来源/API 定向回归与 D04b 合并执行：`17 passed`；三项登录来源启用条件和能力状态持久化通过。
- `uv run pytest -q tests/test_storage.py` → `8 passed`；新增 0018 迁移重复执行、外键与既有迁移清单通过。
- 实际 Electron：以 `--user-data-dir=/private/tmp/jobfindsme-d04a-smoke` 启动，确认 `desktop-v3` 灰白左导航、留白卡片、岗位列表/来源状态右侧工作区仍保持。未输入账号或验证码、未检索、未投递。自动辅助点击未可靠切换来源页，因此未把真实远程页挂载写成人工已验证结论。

## 限制

- BOSS、智联、前程无忧仍需要用户在右侧原页面完成真实登录，随后逐项验证登录、列表、详情、字段、分页及投递页；D01 保持 blocked。
- 浏览器后台视图与能力回写契约已存在，但三个登录平台的生产检索动作桥须在 D04 真实验收时按平台实现和验证，不能退回旧公共 CDP 前置。
