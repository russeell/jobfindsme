# D52 研究输入框与工作区入口修复（2026-09-24）

## 改动与验收

- 研究输入框由同一外容器按正常文档流排列上下文、文本域、主题/提交工具栏和简短说明。焦点落在容器边框，文本域保留键盘可见焦点但不再用自身粗框覆盖按钮；长问题、手动拉高文本域和窄窗仍按高度推开工具栏。主题改为小型圆角芯片，输入内容用于公开网页检索的隐私提醒保留。
- 主侧栏只有找工作、岗位研究、已看过，底部是统一设置。设置内可切换岗位来源与模型；找工作中的“选择来源”和错误提示仍直达来源面板，返回按钮回到原工作页。
- 简历维护复用原 `ResumePage`，由找工作标题旁小按钮打开。弹层支持上传/替换、逐项核对/确认和清除；关闭不会卸载找工作页，因此关键词、筛选、结果和选中岗位保留。维护后立即刷新当前简历状态。弹层有初始焦点、Tab 范围、Escape 关闭及焦点归还；原生网页面板在弹层打开时遮挡，关闭后恢复。
