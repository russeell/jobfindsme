# D25 左侧菜单不再隐藏右侧原生网页

2026-09-19，最终隔离包 `D27-20260919-ui11`，路径 `/private/tmp/JobFindsMe-D27-UI11.app`。UI9 当前运行实例未关闭、未覆盖，验收使用独立合成岗位 profile。

## 原因与修复

UI9 把任何 `aria-modal=true` 弹层一律当成全局模态。普通筛选也设置该属性并带全屏拦截层，所以左侧菜单会隐藏右侧 WebContentsView；不是用户运行旧版本造成。

普通菜单改为非模态、限制在左侧工作区，外部点击可直接穿行到目标操作。原生网页按当前 DOM 的真实相交矩形决定遮挡；全局模态仍隐藏。每次重新计算当前弹层，不用累计计数；ResizeObserver/MutationObserver/焦点通知在关闭和卸载时释放。嵌套 portal 保留父菜单关系，Escape 仅关闭最上层。

## 最小验证及真实证据

- [几何记录](https://github.com/russeell/jobfindsme/blob/1beb7dbe4c465ade47452ae706de487a3582b0eb/docs/desktop/evidence/D25/native-geometry.json)：34 个样本。实际腾讯岗位页先滚动至 300；7 项筛选与岗位状态菜单逐一打开/关闭，原生 `getVisible()` 一直为 true，URL/滚动/标签未改变；期间无一次 null layout 调用，原生 session 对象相同。
- 单次点击切换筛选、Escape 回焦点、外部点击、原生网页获得焦点均通过。用真实 PopoverButton 组件的独立测试根验证嵌套 Escape、外部点击、隐藏触发器和组件卸载，无残留菜单。
- 实际矩形覆盖才隐藏，移回左边或移除恢复；定时检索全局模态隐藏/恢复。模态中切换当前标签仍隐藏，关闭后恢复新标签及正确 bounds。
- 第二真实页面采用腾讯招聘官网。百度招聘页本次加载超时，未把未加载视为验收通过。1240px 分栏再次检查城市、来源、更多筛选均在左侧。
