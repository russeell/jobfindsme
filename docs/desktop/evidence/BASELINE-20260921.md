- 存储迁移回归的预期清单滞后于实现，补齐已存在的 0025–0031 迁移，仍明确检查迁移清单、重复执行和外键。

## 可复现验证

在仓库根目录执行；Node/Python 依赖使用现有安装环境，本轮没有重装依赖。

```sh
npm test --prefix apps/desktop
npm run build --prefix apps/desktop
for suite in tests/desktop_api tests/resume_editor tests/models tests/profiles tests/connectors tests/test_storage.py; do
  .venv/bin/python -m pytest "$suite" -q --tb=short || exit $?
done
git diff --check
```

- Python 分组共 171 项通过：desktop_api 69、resume_editor 9、models 12、profiles 21、connectors 50、storage 10。
- Node 共 67 项通过。初次沙箱运行 66 项通过，唯一失败是 HTTP 错误提示测试无法监听回环端口；取得权限后单独复跑所在文件 5 项全部通过。
- Python 中桌面 API 启停和无密钥本地模型 HTTP 测试同样先受回环端口权限限制，取得权限后各自复跑通过。
- TypeScript 类型检查、Vite renderer 构建、Electron TypeScript 构建通过。
- Python 各目录单独运行，避免已有同名 `test_service.py` 收集冲突；全局 importlib 模式也不适用，因旧测试使用同目录直接导入。未将合并执行整个测试树描述为通过。
- Starlette/AnyIO 存在一条弃用警告，不影响本轮结果。
