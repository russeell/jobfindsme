# D14 模型、来源、独立滚动与浏览器阅读体验

2026-09-19。实施/验证仅使用隔离 Electron 用户目录和合成资料。未操作既有正式 `.app` 登录窗口、读取/导出/清除用户 Cookie、调用付费模型、提交申请或发布。

## 已实现

- 模型设置提供 DeepSeek、通义千问、智谱、豆包、Kimi、硅基流动、OpenAI、Claude、Gemini、Ollama、LM Studio、自定义预设。协议、基础地址、模型 ID 独立可修改；不猜测可用模型 ID。修改连接后重新测试，提供编辑、取消和失败状态。
- 数据库迁移 `0025_model_auth_mode.sql` 显式保存 `api_key/none`。免密仅允许 localhost/127.0.0.1/::1，HTTP 仍限本机；OpenAI/Anthropic/Gemini 分别使用真实协议。免密不写入或发送伪 Key，切换认证模式会解绑旧秘密；云端保留系统加密存储与必需密钥检查。研究与简历修改也支持已测试的本地免密连接。
- 默认每页 10 条。发现岗位使用视口剩余高度，列表和 JD 独立滚动，分页不进入列表滚动内容。筛选区可单独滚动；城市弹层经 Portal 显示，避免被固定高度裁切，打开时隐藏原生网页覆盖层。
- 代码生成方框居中小写 j：SVG 与相同几何的 PNG/ICNS；Vite public 目录与 macOS CFBundleIconFile 均接入。图标生成脚本使用 Pillow，无图像生成服务。
- “岗位来源”仅保留来源、中文登录/检索状态、打开/登录与必要检查动作；11 家公司均有 HTTPS 官网浏览入口、独立 persist partition。浏览目录不扩大自动检索门禁，研究正文解析仍限已支持的五个来源。
- 右上角浏览器开关保留最近页面。浏览器默认期望宽 760px、分栏最小 560px，空间不足时切换主工作区，不挤入列表/JD/浏览器三栏。工具条提供“放大浏览器 / 返回分栏”；放大时临时收起导航，返回恢复存储宽度。原生网页保持正常缩放和自身滚动。
- 侧栏使用统一 SVG 线性图标：搜索、文档放大镜、历史、个人资料、规则、建筑、芯片。每个按钮有名称 tooltip、aria-label、选中态；独立 panel-left 展开按钮固定顶部，j 不承担展开动作。

## 登录保存机制核对

`source-browser-policy.ts` 为每个来源使用固定、不同的 `persist:jobfindsme-source-*` 分区；`source-browser.ts` 前景/后台视图共享同一来源分区。关闭/收起只隐藏或移除 view，不调用 clearStorageData/clearCookies。正式目录包名称仍是 `jobfindsme-desktop`（与既有包一致），Electron 默认 userData/sessionData 路径稳定；本轮测试通过命令行指定 `/private/tmp/...` 隔离路径，未改变正式路径。

UI 说明重启可恢复平台允许持久保存的会话，临时会话、服务器失效或过期需重新登录；无需导出 Cookie，应用不记录密码。没有真实登录凭据，未声称完成三平台登录后重启实测；D01 的真实登录验证仍 blocked。

## 实际验证

- 腾讯匿名真实检索 58 条，10 条/页、6 页。原生窗口滚动列表至底部：`listScroll=955`，`detailScroll=0`，主内容 `scrollTop=0`；分页仍在视口内。浏览器展开时同样可访问分页与 JD，见 `D14/D14-list-scroll.png`、`D14-list-with-browser.png`、`D14-scroll.json`。
- 全部 11 家官网入口可见；实际打开阿里巴巴官方首页（`talent.alibaba.com/?lang=zh`），收起/恢复保留页面；自动检索状态仍“支持官网浏览”。见 `D14-sources.png`、`D14-company-browser.png`。
- 默认 1240×788 内容窗口：正常网页区域 1027×664，放大后 1175×706；原生 bounds 与 DOM slot 相符，均未越界。放大/还原前后同一 webContents id=2、相同 URL，浏览器宽度设置 760 与侧栏宽度保持；原网页可独立向下滚动。见 `D14-expanded-bounds.json`、`D14-restored-bounds.json`、`D14-browser-expanded.png`、`D14-browser-restored.png`、`D14-semantic-nav.png`。
- 真实 UI 选择 Ollama 本机预设，改为本机模拟服务 `127.0.0.1:19144/v1` / `fixture-only`，不填 Key，保存后测试成功。模拟服务实际收到 `/v1/chat/completions` 且无 Authorization 头。仅验证协议链路，不冒充已安装/调用 Ollama 模型或云端模型。见 `D14-model-local.png`。
- Electron 26 tests passed；Python gateway 12 passed（含本机真实 HTTP 请求）、desktop API 10 passed。沙箱限制的本机端口启停测试在允许本机端口的环境重跑通过；保留一个既有 Starlette deprecation warning。TypeScript、Vite、Ruff 和 diff 检查通过。
- 最新 Python runtime 与目录包构建成功；独立包 [D14开发包（已归档）](../../../.development-archive/2026-09-19-d20/tmp/jobfindsme-d14-preview/JobFindsMe.app) 审计通过，启动实际返回 connected=true、15 来源、品牌图像载入。图标 plist 为 `jobfindsme.icns`。见 `D14/package-startup.json`。未覆盖已有正式包。
