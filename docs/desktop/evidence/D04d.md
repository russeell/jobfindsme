## 能力门禁与浏览器桥审计

- 修复了“来源必须先 enabled 才能检索、但产品内没有验证动作”的永久闭环：来源页现提供“登录后验证检索”。它只对 BOSS/智联/前程无忧开放，固定关键词 `Python`，最多两页；只有返回岗位且核心字段成立时才将 session/list 标为 verified 并启用。完整详情、字段和分页分别按实际证据记录 verified/partial。
- 验证 IPC 和正式检索 IPC 都检查调用者必须是主窗口 renderer；远程 `WebContentsView` 无 preload/Node 权限，固定脚本、来源 ID、HTTPS 主机、字段长度和每页数量均受限。前景/背景视图分离但按来源共享持久 partition，不导出 Cookie，也不暴露任意 URL/JavaScript/CDP。
- 候选字段来源可追溯：腾讯映射官方 JSON 的 `RecruitPostName/Responsibility/LocationName/BGName/PostId`；猎聘映射官方列表 JSON，原页正文只用于可视核验。缺失薪资/经验等字段保持 unknown，不推断。
- `ERR_ABORTED` 不再凭白名单目标直接当成功：仅作为同源 SPA 候选，随后有界等待视图实际落到白名单 URL 且主框架停止加载；合法 URL 未完成加载仍抛错。覆盖同源成功和永不就绪失败边界。
