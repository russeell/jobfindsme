# D43 单条历史记录移除

日期：2026-09-23；交付版本：`D45-20260923-ui33`。

- 简历版本和研究报告各有单条“移除记录”及目标确认。SQLite `hidden_at` 仅从普通历史隐藏，证据和快照仍保留。当前简历、被搜索快照/定时任务/研究报告引用的版本返回 409；跨工作区返回 404；删除在单条事务中完成。
- 合成数据 API 验证涵盖当前版拒绝、引用版拒绝、跨工作区拒绝、历史列表更新和隐藏后快照仍可读取；报告移除后列表不再出现，内容仍可用于内部审计。未删除真实用户资料。
- 原生 QA33 隔离资料目录导入合成简历 v1，维护技能后保存 v2。v1 的“移除记录”弹出单条目标与隐藏语义，确认后历史计数从 2 变 1；当前 v2 保留。约 865px 窄窗下确认当前 v2 和“版本历史 · 1”仍可读。
- 同一隔离目录创建两份合成研究报告，在窄窗对旧问题报告 v2 点击“移除记录”，确认内容包含公司、岗位、v2 及快照保留说明；确认后历史计数从 2 变 1，v1 仍可见。没有触碰用户现有简历或报告。
- 本轮相关 41 项 Python 定向测试通过，`ruff check` 通过。

- 退出并重启隔离 QA33 应用后，当前简历 v2 与“版本历史 · 1”仍在；研究报告历史仅有合成 v1 与 v3，已移除的 v2 不再列出。隔离库只读核对显示简历 v1、报告 v2 的 `hidden_at` 非空，原始快照保留。
