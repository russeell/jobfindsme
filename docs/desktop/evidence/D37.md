# D37 验收记录

日期：2026-09-20。版本目标：`D37-20260920-ui20`。

## 结果

- 来源目录扩为 4 个平台与 16 家公司，新增 DeepSeek、MiniMax、智谱、月之暗面、阶跃星辰。每个来源使用独立持久分区；Moka 仅允许已从公司官网观察到的精确租户路径。
- 首选连接器失败后，桌面主进程可在同来源分区内读取真实列表链接、有限续页和按需 JD。相同请求合并并缓存 2 分钟，风险控制暂停 5 分钟，取消会阻止排队请求开始。
- DeepSeek 使用官网脚本内的岗位快照并保留快照时间；MiniMax 与小米仅调用详情页实际发出的同源公开接口。响应按 200 KB 上限流式读取，岗位 ID 与请求 URL 必须一致。
- 岗位详情改为用户点击时读取并持久化，不再在列表检索阶段串行读取前三条。来源选择继续使用既有 `jfm.sources.selected` 本地状态；新增来源不会自动选中，定时任务保存的来源快照不变。
- 完整能力与缺口见 [source-matrix.json](https://github.com/russeell/jobfindsme/blob/1beb7dbe4c465ade47452ae706de487a3582b0eb/docs/desktop/evidence/D37/source-matrix.json)。可用状态只授予真实列表和完整 JD 均已观察到的来源；阿里、京东、智联、前程无忧的缺口保持可见，没有被写成空结果或“已可用”。
