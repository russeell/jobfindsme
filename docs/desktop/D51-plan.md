# D51 研究工作台收尾（2026-09-24）

最终界面以已确认岗位为上下文：输入框内直接切换公司与岗位主题，两项默认选中；文字问题进入有界的公开资料检索。首次提交保存报告，报告下方继续追问会保存新版本并列出本次问题对应的原文，缺原文明确说明无法回答。历史报告从页眉统一进入，返回研究首页不删除当前报告。无岗位时先粘贴并确认原页。
