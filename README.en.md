# JobFindsMe

A local desktop workspace for job search, public reputation research, resumes, job records and scheduled searches. Electron/React owns the UI and browser sessions; Python owns the local API and business services.

See the [Chinese README](README.md) for setup and the current directory tree, [desktop documentation](docs/desktop/README.md) for status, and [migration manifest](docs/desktop/STRUCTURE.md) for module boundaries.

The current build is developed and verified locally on macOS. Source login and complete extraction remain separate acceptance checks; not every registered source is fully verified. Applications are submitted by the user on the original website.

The Python distribution name and existing CLI/MCP entrypoints are retained for compatibility. Native plugin marketplace manifests have been retired. [Legacy documentation](docs/legacy/README.en.md) is not the desktop product specification.
