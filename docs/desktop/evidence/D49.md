# D49：求职主流程与历史兼容

2026-09-24，离线合成数据验收。普通包：`/private/tmp/JobFindsMe-D49-Flow.app`；独立 QA 包：`/private/tmp/JobFindsMe-D49-FlowQA.app`，使用 `jobfindsme-preview-D49-flow` 隔离资料。普通包未启动；QA 包已退出。没有读取用户真实简历或复制浏览器登录态。

## 已实现

- 非当前简历版本和匹配规则可逻辑隐藏，旧搜索、报告和已停用计划的引用快照仍保留。当前简历通过独立接口清除当前指针；重启后无简历关键词搜索继续可用。
- 主导航移除匹配规则，找工作页隐藏数字分数和评分模式；已确认简历只显示岗位对应线索，普通搜索不自动调用模型。历史规则和分析数据没有改写。
- 简历页集中上传、核对、确认、清除当前简历和求职偏好。偏好持久保存，岗位词、城市、薪资进入下次桌面检索；明确城市或薪资时未知值不当作满足。
- 岗位发布日期只显示来源提供的日期或“未知”，完整 JD 和薪资缺失保持未知；现有去重、来源失败保留成功结果、报告保存重开与再次调查路径通过回归。
- README 中英双语与技术文档更新；D46 首页图保留并标为历史导航。
