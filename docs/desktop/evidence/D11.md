## 结果

- 新增产品内 SQLite 持久调度服务、运行记录和通知出站表，不依赖 Codex 自动化。任务创建时固定用户筛选、选定来源、已确认简历版本和评分规则版本。
- 支持间隔/每日/每周、IANA 时区、暂停、恢复和 `once/skip` 补跑策略。`task_id + scheduled_for` 唯一，单任务运行中不重入；多次错过只执行一次补跑并把下次计划推进到当前时间之后。
- 实际执行复用 D04b 后端来源登录/能力门禁和 D05 快照排序，并显式传入任务绑定的简历版本。登录失效为 `login_required`，部分来源失败为 `partial`，不冒充空结果。
- 新增和岗位内容变化基于上一次任务快照判定；新增、变化和需用户处理的失败才产生通知，相同可操作事件按指纹去重。
- Electron 在应用运行或窗口隐藏后每分钟轮询到期任务；完全退出时停止 Python 服务与轮询。界面明确不承诺休眠/关机唤醒。
- 旧 `monitor_configs` 只读审查数量；由于缺少简历/评分快照与时区，不自动激活，界面要求用户重新确认，避免迁移后静默执行错误计划。
