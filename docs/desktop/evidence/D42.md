# D42 双主题紧凑岗位调研

日期：2026-09-23；交付版本：`D45-20260923-ui33`。

- 主页面只提供“公司评价”和“岗位情况”两个可多选主题。公司、岗位标题、JD 与链接从目标岗位带入；未知公司才要求补充。公开来源由应用固定选择，不要求用户逐个配置。
- 公司主题分别搜索正向与负向线索；岗位主题查工作内容、强度、假期与福利。检索最多 30 秒，逐来源逐查询限定 RSS 项与原文核验量；检索角度不当作原文立场。报告按主题保存证据、原链接与未查明项；旧报告原问题继续显示。
- 合成数据验证：`tests/desktop_api/test_research.py` 的双主题、公司单主题与旧报告用例。与 D43/D44 相关接口测试合计 41 项通过；仅需本地端口的进程用例在允许 localhost 的隔离执行中另行通过。`ruff check` 和桌面 TypeScript 构建通过。
- 原生 QA33 隔离资料目录写入两份合成报告。打开双主题报告后，可见“公司评价”“岗位情况”分组、分别的未查明说明和默认勾选的两个主题；没有因缺原文生成公司口碑结论。旧报告通过离线读取用例验证自定义问题不丢失。
- 原生窗口缩至约 865px 后，双主题报告、未查明项和历史列表仍可读；切换旧版 v2 后显示“本次兴趣问题：旧版自定义问题：团队如何协作？”。
